# Nexo

Plataforma donde los clientes pueden buscar y solicitar servicios variados, y donde otros usuarios (prestadores) ofrecen dichos servicios. Los servicios pueden ser de tecnología, estructuras, eléctricos, reparaciones, entre otros.

## Tecnologías
- Por definir — el enfoque de este proyecto es la aplicación de Scrum, no el desarrollo del producto.
    

## Organización

El proyecto se desarrolla utilizando **Scrum** y se organiza en diferentes Sprints.

El repositorio contiene:
- Product Backlog (`docs/product-backlog.md`)
- Historias de usuario (`docs/user-stories.md`)
- Documentación de cada Sprint (`docs/sprints/`)
- Código fuente (`src/`)
- Historial de cambios mediante commits
