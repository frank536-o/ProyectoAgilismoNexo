# Product Backlog — Nexo

## Épica 1: Módulo de usuario

### Feature 1.1: Registro usuario
- US-01: Como usuario quiero registrarme para utilizar la plataforma.
- US-02: Como usuario quiero revisar mis datos de registro para crear mi cuenta.

### Feature 1.2: Inicio de sesión
- US-03: Como usuario quiero iniciar sesión para acceder a la plataforma.
- US-04: Como usuario quiero cerrar sesión en la plataforma para proteger mi cuenta.

## Épica 2: Módulo de servicio

### Feature 2.1: Publicación de servicio
- US-05: Como prestador quiero publicar mis servicios para el cliente.

### Feature 2.2: Consulta de servicio
- US-06: Como cliente quiero consultar un servicio para encontrar uno que necesite.

## Épica 3: Reserva del servicio

### Feature 3.1: Solicitud de reserva
- US-07: Como cliente quiero reservar un servicio para contratarlo.

### Feature 3.2: Gestión de reserva por prestador
- US-08: Como prestador quiero gestionar las solicitudes de reserva para aceptar o rechazar un servicio.

## Épica 4: Módulo de pago

### Feature 4.1: Métodos de pago
- US-09: Como cliente quiero escoger el método de pago para pagar el servicio contratado.

### Feature 4.2: Pago del servicio
- US-10: Como cliente quiero pagar el servicio para confirmar mi reserva.
- US-11: Como prestador quiero recibir el pago para prestar el servicio.

## Épica 5: Calificaciones

### Feature 5.1: Calificar el servicio
- US-12: Como usuario quiero calificar el usuario para expresar mi experiencia.
