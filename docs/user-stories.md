# Historias de Usuario — Nexo

## US-01 — Registro de usuario
**Como:** usuario
**Quiero:** registrarme
**Para:** poder utilizar la plataforma.

### Criterios de aceptación
- El usuario debe ingresar nombre, correo electrónico y contraseña.
- El sistema debe validar que el correo no esté registrado previamente.
- El usuario debe recibir confirmación del registro.

**Prioridad:** Alta
**Estimación:** Por definir

---

## US-02 — Revisión de datos de registro
**Como:** usuario
**Quiero:** revisar mis datos de registro
**Para:** crear mi cuenta correctamente.

### Criterios de aceptación
- El sistema debe mostrar un resumen de los datos ingresados antes de confirmar.
- El usuario debe poder corregir algún dato antes de finalizar el registro.

**Prioridad:** Media
**Estimación:** Por definir

---

## US-03 — Inicio de sesión
**Como:** usuario
**Quiero:** iniciar sesión
**Para:** acceder a la plataforma.

### Criterios de aceptación
- El sistema debe validar correo y contraseña.
- El sistema debe mostrar un mensaje de error si las credenciales son incorrectas.

**Prioridad:** Alta
**Estimación:** Por definir

---

## US-04 — Cierre de sesión
**Como:** usuario
**Quiero:** cerrar sesión en la plataforma
**Para:** proteger mi cuenta.

### Criterios de aceptación
- El usuario debe poder cerrar sesión desde cualquier pantalla.
- Al cerrar sesión, el sistema debe redirigir a la pantalla de inicio.

**Prioridad:** Media
**Estimación:** Por definir

---

## US-05 — Publicación de servicio
**Como:** prestador
**Quiero:** publicar mis servicios
**Para:** ofrecerlos al cliente.

### Criterios de aceptación
- El prestador debe poder ingresar título, descripción, categoría y precio del servicio.
- El servicio publicado debe quedar visible para los clientes.

**Prioridad:** Alta
**Estimación:** Por definir

---

## US-06 — Consulta de servicio
**Como:** cliente
**Quiero:** consultar un servicio
**Para:** encontrar uno que necesite.

### Criterios de aceptación
- El cliente debe poder buscar servicios por categoría o palabra clave.
- El sistema debe mostrar los resultados con información básica del servicio.

**Prioridad:** Alta
**Estimación:** Por definir

---

## US-07 — Solicitud de reserva
**Como:** cliente
**Quiero:** reservar un servicio
**Para:** contratarlo.

### Criterios de aceptación
- El cliente debe poder seleccionar fecha y detalles de la reserva.
- El sistema debe enviar la solicitud al prestador correspondiente.

**Prioridad:** Alta
**Estimación:** Por definir

---

## US-08 — Gestión de reserva por prestador
**Como:** prestador
**Quiero:** gestionar las solicitudes de reserva
**Para:** aceptar o rechazar un servicio.

### Criterios de aceptación
- El prestador debe poder ver las solicitudes pendientes.
- El prestador debe poder aceptar o rechazar cada solicitud.
- El cliente debe recibir notificación de la respuesta.

**Prioridad:** Alta
**Estimación:** Por definir

---

## US-09 — Métodos de pago
**Como:** cliente
**Quiero:** escoger el método de pago
**Para:** pagar el servicio contratado.

### Criterios de aceptación
- El sistema debe mostrar los métodos de pago disponibles.
- El cliente debe poder seleccionar uno antes de confirmar el pago.

**Prioridad:** Media
**Estimación:** Por definir

---

## US-10 — Pago del servicio
**Como:** cliente
**Quiero:** pagar el servicio
**Para:** confirmar mi reserva.

### Criterios de aceptación
- El sistema debe procesar el pago con el método seleccionado.
- El sistema debe confirmar la reserva una vez procesado el pago.

**Prioridad:** Alta
**Estimación:** Por definir

---

## US-11 — Recepción de pago
**Como:** prestador
**Quiero:** recibir el pago
**Para:** prestar el servicio.

### Criterios de aceptación
- El sistema debe notificar al prestador cuando el pago haya sido confirmado.
- El monto recibido debe reflejarse en el historial del prestador.

**Prioridad:** Alta
**Estimación:** Por definir

---

## US-12 — Calificación del servicio
**Como:** usuario
**Quiero:** calificar el usuario
**Para:** expresar mi experiencia.

### Criterios de aceptación
- El usuario debe poder calificar de 1 a 5 estrellas al finalizar el servicio.
- El usuario debe poder dejar un comentario opcional.
- La calificación debe quedar visible en el perfil del usuario calificado.

**Prioridad:** Media
**Estimación:** Por definir
