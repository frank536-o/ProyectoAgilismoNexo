# Sprint 1 — Sprint Review

## 1. Objetivo del Sprint

Desarrollar las funcionalidades iniciales de gestión de usuarios de Nexo, permitiendo que los usuarios puedan registrarse, revisar sus datos de registro, iniciar sesión y cerrar sesión.

**Duración planeada:** 2 semanas.

## 2. Historias de usuario seleccionadas

- US-01: Registro de usuario.
- US-02: Revisión de datos de registro.
- US-03: Inicio de sesión.
- US-04: Cierre de sesión.

## 3. Historias completadas

- Pendiente de confirmar con el equipo.

## 4. Historias no completadas

- Pendiente de identificar las historias que no se completaron.

## 5. Incremento del producto

Durante el Sprint 1 se avanzó en el diseño de algunas pantallas del frontend y en el desarrollo de parte del código y la lógica del backend.

Estos avances constituyen una primera aproximación a las funcionalidades de gestión de usuarios. Sin embargo, todavía falta completar parte del desarrollo y realizar pruebas funcionales.

Por esta razón, no se afirma que las funcionalidades estén completamente operativas.

## 6. Dificultades identificadas

La principal dificultad fue la organización del trabajo dentro de los sprints. Al equipo le ha costado distribuir las actividades y organizar el desarrollo de las historias de usuario.

Además, no se realizaron pruebas durante este sprint, por lo que aún no se ha validado el funcionamiento de las funcionalidades desarrolladas.

## 7. Aspectos por mejorar

- Dividir las historias de usuario en tareas más pequeñas.
- Definir responsables y prioridades.
- Mejorar el seguimiento de las tareas durante el sprint.
- Establecer criterios de aceptación claros.
- Incluir pruebas funcionales antes de dar por terminada una historia.

## 8. Resultado del Sprint

El Sprint 1 permitió iniciar el desarrollo de las funcionalidades de gestión de usuarios de Nexo. Se obtuvieron avances en el frontend y el backend, pero el equipo debe confirmar cuáles historias quedaron terminadas y cuáles continúan pendientes.
